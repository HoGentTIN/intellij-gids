# Visual Paradigm integreren (niet nodig voor OOSDII)

⚠️ De integratie van VP (Visual Paradigm) in Intellij kan problemen veroorzaken. Je kan VP beter stand-alone runnen.

Had je VP al geïntegreerd en veroorzaakt dit problemen? Je kan de integratie ongedaan maken door onderstaande stappen te volgen:

1. Sluit IntelliJ af.
2. Voer Visual Paradigm als administrator uit.
3. Kies bovenaan in het tabblad **Window** voor **Integration** > **IDE Integration...**
4. Klik bovenaan in het pop-up venster **Uninstall** aan en vink het vakje bij **Intellij** aan.
5. Bevestig dat je de integratie wil verwijderen.
