# Handleidingen IntelliJ IDEA

Deze github repository bevat alle instructies voor installatie en configuratie van IntelliJ IDEA. De .md bestanden in de repository worden weergegeven als website dankzij Github Pages.

De website bevindt zich op <https://hogenttin.github.io/intellij-gids/>.

Als je een pagina wil toevoegen:
- plaats de nieuwe .md file in de repository op een gepaste plaats
- in de .md file moet je een front matter toevoegen, zodat deze herkend wordt als pagina voor de website. De front matter bestaat uit twee keer drie liggende streepjes, op twee lijnen (zie andere .md files voor voorbeelden).
- zorg dat de link naar de pagina in het zijmenu verschijnt door deze toe te voegen in [/_config.yml](/_config.yml).
